# 商店素材清單（Stage 0 · 僅文件）

此清單供日後 App Store／Google Play 上架準備，**不是**已定稿行銷文案，亦未授權任何追蹤或分析 SDK。

## 圖示

- [ ] App Store：1024×1024 主圖示（無透明、無圓角由商店裁切）
- [ ] Google Play：512×512 高解析圖示
- [ ] 對齊現有品牌色與「題」字標（參考 `lib/appIcon.tsx`／動態 `/icons/192`、`/icons/512`）

## 截圖（建議各平台最少張數依當期規範）

拍攝真實產品畫面，勿虛構未上線功能：

- [ ] 首頁選題庫
- [ ] 練習作答中
- [ ] 模考計時／結果
- [ ] 複習（錯題）
- [ ] 統計（熱力或備份區）
- [ ] （選用）CLI 實驗畫面（Cisco／華為）
- [ ] iPhone 與（若上架）Android 常見解析度各一組

## 商店文字欄位（待擁有者定稿）

- [ ] 應用名稱／副標題（與「題庫刷題」一致或經批准之變體）
- [ ] 簡短說明、完整說明（繁中；若需英文另譯）
- [ ] 關鍵字／類別（教育／參考）
- [ ] 年齡分級問卷答案
- [ ] 支援 URL → 正式站 `/support`（部署後完整 URL）
- [ ] 隱私政策 URL → 正式站 `/privacy`
- [ ] 行銷 URL（選用；可為網站首頁）

## 隱私與權限申報（對照現況）

- [ ] 無帳戶／登入 → 無需帳戶刪除流程（須在政策說明）
- [ ] 本機儲存（進度）
- [ ] 可選通知（回來刷提醒；非伺服器推播）
- [ ] 可選麥克風（口說）
- [ ] 字型 CDN（Google Fonts）連線
- [ ] 無分析／廣告 SDK（若日後加入須更新政策與標籤）

## 平台帳號與建置

- [ ] 確認 Apple Developer 會籍有效
- [ ] （Android）取得 Google Play 開發者帳號
- [ ] 依 `docs/ios-capacitor.md` 執行 `npm run native:www` → `npx cap sync ios` → Xcode Archive（Linux CI 無法簽名）
- [ ] 確認送審包為本機 `www` UI（**不含**正解題庫），連線批改走 API；而非只開遠端整站 WebView
- [ ] `npm run native:audit-www` 通過（無 offline-bank 產物）
